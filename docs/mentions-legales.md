## 2. Objet du service

Mila est une plateforme permettant notamment aux utilisateurs de créer, gérer et partager des listes de naissance et, selon les fonctionnalités disponibles, d'autres types de listes de cadeaux.

La plateforme permet notamment :

- la création de listes privées ou publiques ;
- l'ajout de produits provenant de différents sites marchands ;
- l'affichage d'informations relatives aux produits ;
- la réservation de cadeaux par des proches ;
- l'ajout de messages destinés aux bénéficiaires ;
- la contribution financière à certains cadeaux ou objectifs ;
- la gestion éventuelle d'une cagnotte ;
- le paiement via les moyens de paiement proposés par Mila ;
- et, lorsque cette fonctionnalité est proposée, la facilitation de commandes auprès de marchands tiers.

Certaines fonctionnalités peuvent évoluer, être ajoutées ou retirées.
